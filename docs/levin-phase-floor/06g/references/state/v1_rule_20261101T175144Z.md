**The calls.** The 12 rows of R23/R24 with `V1 == VIOLATES` in the rehearsal agent's
`rehearsal/out/qsi_rows.csv` (read only); in each, the group call of sub-interval 1, group `G+q+r`,

atol -32. v23, e23, v24, e24 are that group's `value` and `abserr` in each store's

`rehearsal/scripts/v1_violations_detail.py` reads it), in `float.hex`. Ids w00..w11, ordered by
(k, z_response).

**The captures.** At g: the code worktree (1c5336e) against R24; the capture must reproduce v24 and
e24 bit for bit. At the parent: the parent worktree (4f4f9ed) against R23; it must reproduce v23 and
e23 bit for bit. The two captures' groups must be bit-identical (route, span, signs, each active
factor's phase spline and leading table, as compare13.py compares Route B groups; and the integrand
values at 65 points and the default edges). Any failure is a stop. The ten store files are opened
`mode=ro` only, nothing is created beside them, and all ten are hashed (SHA-256) before and after
against `rehearsal/state/stores_sha256_final.txt`; a difference is a stop. No Ray, no lock.

**The readings.** Route B, the four readings of `tools.filon_reference` on the g capture (QAWO and
FCC at resolutions 1 and 2), each in its own process, stopped at 30 minutes.

**The count rule:** all four present, scatter at most min(e23, e24)/100, every reading's
`all_monotone` true. Never loosened; a call that does not count is recorded with its four readings
and their scatter.

**The fields** (`out/v1_groups.json`, table `out/v1_groups.md`, separate from V3's; descriptive, no
prediction): per call, k, q, r, z_response, the group; its four readings, scatter, tolerance, wall
times, whether it counted; for each counted call the reference (FCC res 2), v23 and e23, v24 and e24,
and |v - ref|/e for each code, every value in `float.hex`. The question per call: which code is
nearer the reference, and does that code's declared error cover its distance from it. Numbers only.
