usage: python -m raypoolkit.rehearsal_lock [-h]
                                           {acquire,set-pid,release,status,ray-processes}
                                           ...

The shared rehearsal lock. Never breaks, waits for or retries a lock; a held
lock means stop and ask the user.

positional arguments:
  {acquire,set-pid,release,status,ray-processes}
    acquire             take the lock (exit 3 if held or the old location
                        exists, 4 if a process is alive)
    set-pid             record a live pid in the caller's lock
    release             release the caller's lock (exit 1 if refused)
    status              the lock, its owner, the old location, and the
                        processes
    ray-processes       the processes of a temp dir (exit 1 if any)

options:
  -h, --help            show this help message and exit
