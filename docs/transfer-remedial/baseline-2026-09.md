### 3.1 The mechanism, measured directly

The ODE right-hand side is `dQ/dlog x = (2/pi)/(x m(x)) - Q`, and `(2/pi)/(x m(x))` is
identically `1 + O(nu^2/x^2)`. Sampled at five *adjacent doubles*:

| nu | x | five adjacent values of (2/pi)/(x m(x)) |
|---|---|---|
| 0.5 | 1e+15 | 1.000000, 1.000000, 1.000000, 1.000000, 1.000000 |
| 0.5 | 3e+15 | 0.988677, 0.939033, 0.944549, 1.001489, 1.064185 |
| 0.5 | 1e+16 | 0.750691, 1.685941, 0.833489, 0.872832, 1.639993 |
| 2.5 | 1e+15 | 1.000000, 1.000000, 1.000000, 1.000000, 1.000000 |
| 2.5 | 3e+15 | 0.946862, 0.758635, 0.776589, 1.007340, 1.419559 |
| 2.5 | 1e+16 | 0.969553, 0.919969, 1.169766, 0.906840, 0.989287 |

So the failure is upstream of the integrator: SciPy/Amos `jv`/`yv` lose
argument-reduction accuracy, `m` becomes O(1)-relatively noisy, and DOP853 at
`rtol=5e-14` cannot pass its error test on noise, so it drives the step size to zero.
`np.sin`/`math.sin` are **not** implicated — `RECONCILIATION.md` §1 confirms them
correctly rounded to 1e16 — the degradation is confined to Amos.

### 3.2 The same boundary is order dependent, and it applies to `jv`/`yv`

`RECONCILIATION.md` §1 records the 7.13e8 failure boundary for `hankel1e` at nu in
{100.5, 1000.5}, and 2.247e15 for nu <= 20.5. It did not measure `jv`/`yv`, which are
what every reference and every existing test in this area is built from. They fail at the
same place. Probe: `a = sqrt(pi x/2) hypot(J, Y)`, identically `1 + O(nu^2/x^2)`, so over
`1e8 <= x <= 2e15` it must be 1.000000000000 for every order below.

| 50.5 | 6.37e-14 | 1e+08 |
| 70.5 | 1.24e-13 | 1e+08 |
| 80.5 | 1.62e-13 | 1e+08 |
| 85.5 | 1.83e-13 | 1e+08 |
| 88.5 | 1 | 1.472e+14 |
